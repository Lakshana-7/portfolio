Design system The look is a near-black navy night sky with one violet-to-blue glow, sharp condensed headlines and one italic serif word for personality. Define these as Tailwind theme tokens. Token Value Use bg #090A12 Page background surface #101220 Cards, navbar pill surface-raised #171A2B Hover and active cards border rgba(255,255,255,0.08) All hairlines text #F3F5FB Headlines, body muted #9AA3B8 Secondary text accent gradient  #7C5CFF  to  #3B82F6 Italic words, buttons, active states, glows highlight #F5A524 Badges, key phrases inside paragraphs available #3DDC97 Small "open to internships" dot Typography Headlines:  Barlow Condensed, bold, uppercase, tight leading. Accent word:  Instrument Serif, italic, filled with the accent gradient. Exactly one per headline. Large intro lines:  Instrument Serif, regular. Body:  Inter, 400 and 500. Labels, nav, counters:  JetBrains Mono, small, uppercase, wide letter spacing. Shared section pattern:  a thin line, a mono label such as  03 PROJECTS  (number in accent color), then the big headline, then content. Container max width 1200 px. Section spacing 112 px on desktop, 72 px on mobile. Card radius 16–24 px. Motion:  content fades up 24 px as it enters the viewport (0.6 s, ease-out, 80 ms stagger). Cards lift and glow on hover. Auto-playing carousels pause on hover and on touch. Everything auto-playing stops when the user has reduced motion turned on. Star-field background:  a fixed full-page canvas with slowly drifting stars. Stars near each other draw faint connecting lines, like a constellation, which echoes her Constellia project. Brightest in the hero, about 25% opacity elsewhere. Cap at 60 stars on mobile and pause the animation when the tab is hidden. 4. Navbar and hero Navbar Fixed at the top. Quality, deployment, build order and acceptance checklist Performance:  aim for a Lighthouse performance score of 90 or more on desktop. Lazy-load below-the-fold images, load only the font weights in use, code-split project pages with  React.lazy , and keep the star-field canvas light. Accessibility:  WCAG AA contrast, visible accent focus rings, a skip-to-content link, semantic landmarks, labels on every icon-only button, alt text taken from captions, and  aria-live  for toasts. SEO and sharing:  page title  Lakshana A | AI & Data Science Student and Developer , a meta description, Open Graph and Twitter tags, a favicon and a canonical URL. Responsive:  breakpoints at 640, 1024 and 1280 px. Check at 375, 768 and 1440 px, with no horizontal page scroll at any size. Deployment:  push to a GitHub repo and connect it to Vercel or Netlify. Build command  npm run build , output folder  dist . Add a single-page-app rewrite ( /* /index.html 200  in  public/_redirects  for Netlify, or  vercel.json  for Vercel) so project page links survive a refresh. Build order Scaffold Vite, React, Tailwind and React Router. Add the tokens, fonts and data files with placeholder content.
